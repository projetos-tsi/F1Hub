Política de privacidade

Última atualização: 18/11/2026

A F1 Hub é um projeto acadêmico do curso de Sistemas para Internet do Senac. Esta política descreve como os dados são tratados no site, com base na Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

1. Dados que coletamos2. Dados salvos no seu navegador3. Para que usamos os dados4. Segurança5. Compartilhamento6. Seus direitos7. Alterações desta política

1. Dados que coletamos

Hoje o site não envia dados pessoais para nenhum servidor. Quando o cadastro e o login forem ativados, serão armazenados apenas nome, e-mail, senha protegida e, para a assinatura, a equipe favorita e o tamanho da camiseta escolhidos.

2. Dados salvos no seu navegador

O carrinho de compras fica salvo somente no armazenamento local do seu navegador, para que os itens não se percam ao trocar de página. Esses dados não saem do seu dispositivo e podem ser apagados limpando os dados de navegação ou usando o botão "Limpar carrinho".

Os campos da finalização demonstrativa e do montador da F1Hub Box não são enviados nem armazenados.

3. Para que usamos os dados

Os dados serão usados exclusivamente para identificar você no login, manter sua conta e sua assinatura e exibir suas informações na área do cliente. Não utilizamos os dados para publicidade.

4. Segurança

As senhas nunca serão armazenadas em texto puro: elas são convertidas em um código irreversível (hash) antes de serem salvas no banco de dados. O acesso à área administrativa será restrito a usuários autorizados.

5. Compartilhamento

Os dados não são vendidos nem compartilhados com terceiros. Por se tratar de um projeto acadêmico, eles poderão ser acessados apenas pela equipe e pelo professor responsável, para avaliação do projeto.

6. Seus direitos

De acordo com a LGPD, você pode solicitar a confirmação, o acesso, a correção ou a exclusão dos seus dados a qualquer momento.

7. Alterações desta política

Esta política pode ser atualizada conforme o projeto evolui. A data da última atualização aparece no topo desta página.
