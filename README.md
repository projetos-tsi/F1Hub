F1 Hub 🏎️

Projeto Integrador desenvolvido para o curso de Tecnologia em Sistemas para Internet.

O F1 Hub é um e-commerce focado em produtos de equipes da Fórmula 1, como camisetas, polos, moletons, jaquetas e bonés.

Tecnologias utilizadas
HTML
CSS
JavaScript
PHP
MySQL
Estrutura do projeto
├── backend/      # Lógica da aplicação
├── database/     # Banco de dados, migrations e seeds
├── docs/         # Documentação do projeto
├── frontend/     # Interface do F1 Hub
└── index.php     # Entrada principal do projeto
